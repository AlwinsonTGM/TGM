# TGM — Codex UX concept

Open `index.html` in a browser. This disposable concept compares a compact Home, independent focus, workspace, quick capture and explicit review with the other UX variations. Everything is synthetic and resets on refresh. The terminal, FlowState timer, memory approval and reviewer are simulations: there are no writes to AGY, FlowState, Obsidian, or user data.

Try choosing a suggested step, starting and stopping focus, completing a task, capturing a thought, and opening a memory proposal. The project names expand and collapse their sessions.

The refinement keeps session names visible in compact layouts, brings the last session closer to the first viewport, highlights the first suggested step, and distinguishes the open task from a focus session running in another workspace. Terminal feedback is illustrative and reports only changes to this preview's state.
