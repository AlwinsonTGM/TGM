# TGM — Codex UX concept

Open `index.html` in a browser. This disposable concept compares a compact Home, independent focus, workspace, quick capture and explicit review with the other UX variations. Everything is synthetic and resets on refresh. The terminal, FlowState timer, memory approval and reviewer are simulations: there are no writes to AGY, FlowState, Obsidian, or user data.

Try choosing a suggested step, starting and stopping focus, completing a task, capturing a thought, and opening a memory proposal. Ctrl+K focuses quick capture.
