# TGM

TGM helps its user start meaningful work or study and return to it later.

## Language

**Goal**:
An outcome the user wants to make progress toward. It may be active or archived.

**Next step**:
A manageable action toward a goal that the user can choose to work on.

**Quick capture**:
A thought, question, task, or note saved without needing to categorize it immediately.

**Harness session**:
A work session associated with a particular installed AI harness, such as AGY or OpenCode.

**Focus session**:
A period of focused work tracked by FlowState, which can take place with or without a harness. Stopping the session and completing a task are separate actions.
