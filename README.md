# TGM — Personal Command Center

TGM is a Windows-first personal dashboard in the planning and prototype stage. Its purpose is to help its creator start meaningful work or study, use the real AGY CLI, record focus with FlowState, and review learning in Obsidian. Production implementation has not started.

Start with the [project hub](outputs/project-hub.md), [first-release plan](outputs/first-release-plan.md), and [product context](PRODUCT.md). The [original clickable prototype](outputs/tgm-ux-prototype/index.html) uses synthetic in-memory data and has no live integrations.

Six alternative UX prototypes live on the `ux-*` branches. The [comparison arena](outputs/ux-arena/index.html) can display them once their worktrees are set up locally; see its [setup instructions](outputs/ux-arena/README.md). These are experiments and do not represent production software.

The `work/` directory contains feasibility probes, including isolated copies and test servers. Read the dated reports in `outputs/` for what each probe actually demonstrated and its limitations. Do not use test bridges with real data as production integrations.
