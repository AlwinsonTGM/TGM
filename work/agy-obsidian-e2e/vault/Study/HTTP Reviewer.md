# HTTP Status Codes Reviewer

> [!NOTE]
> Distinguish whether the resource could not be found or if the server experienced a problem processing the request.

## Core Status Codes

- **HTTP 200**: Success.
- **HTTP 404**: The resource was not found.
- **HTTP 500**: The server hit an unexpected condition.

## Practice Question

A client sends a request to an existing endpoint, but the server encounters an unexpected condition while processing it and fails to complete the request.

Which status code should the server return: **200**, **404**, or **500**?
